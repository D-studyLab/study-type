# 勉強のつまずき方診断（study-type）

15問こたえると、**自分がどこで詰まっているか**と、**今日やる1つだけ**が出る。点数の予想はしない。塾で実際によく見る詰まり方を8つに分けた。約2分・`index.html` を開くだけ（送信なし・完全ブラウザ内）。

## 「タイプ名を当てる」診断にしなかった

結果ページに出るのはタイプ名ではなく、**先生に相談したときに返ってくる形**にしてある。

1. **できていること**（先に言う。詰まっている人ほど、できている部分を数えられていない）
2. **いま何が起きているか**（原因の説明。性格の話にはしない）
3. **先生ならこう言う**（まず／つぎに／ずっと の3段階）
4. **今日やる1つだけ**
5. **効かないのでやらなくていいこと**（これが一番効く。真面目な人ほど無駄な努力をしている）

## 設問は「場面」で聞く

「あなたは真面目ですか」のような抽象的な質問は1問も入れていない。全問に**場面**が付いている——テスト3日前／夜9時、部屋／模試が返ってきた／丸つけのあと。

選択肢は**4択**。さらに「**どれも当てはまらない**」を全問に置いてある（点は入らない）。2択だと「どちらでもない」人が必ず出て、無理に選ばせた瞬間に結果が嘘になるため。

## 出方は均等にしていない

8タイプが12.5%ずつになるように調整**していない**。「みんなそう」なパターンも「特殊な」パターンも実在するので、そのまま出す。

ランダム回答3000回での実測（2026-08-09）:

| 出方 | タイプ |
|---|---|
| 26.7% | 優先順位が決まらない型 |
| 15.7% | 質問できない型 |
| 14.5% | 前日にまとめてやる型 |
| 12.0% | わかった気になる型 |
| 10.5% | 完璧主義で止まる型 |
| 7.6% | 人と比べて凹む型 |
| 6.5% | 量はやるが伸びない型 / 集中が続かない型 |

**8タイプすべてに到達すること**と、**1つが半分を超えないこと**の2つだけを条件にしている。最初の版は完璧主義型が43%出る一方で質問できない型に一度も到達せず、配点を組み直した。

## MBTIではない

名前も指標も借りていない。心理検査ではないので、性格を判定しない。**次の一手を1つ決めるための道具**として作っている。合わないと思ったら、いちばん下の「効かないこと」だけ持ち帰ればいい——と結果ページにも書いてある。
